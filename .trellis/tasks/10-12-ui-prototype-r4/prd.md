# Prototype round 4: account type/card editing + 记一笔 redesign

## Goal

继续打磨 `docs/ui-prototype/` 原型。用户两点反馈:

1. **账户类型要可编辑**,且若为银行卡需支持记录**卡号**。
2. **记一笔页面仍不满意**,请重新设计;核心诉求是 **尽量不滑动即可完成快捷记账**。

## Requirements

### A. 账户类型 / 卡号可编辑

* 账户详情子页面:
  * 「类型」行可点击 → 手机内弹层列出全部类型(储蓄/信用/预付/应收应付/借贷/投资/电子钱包/现金),
    选中即生效并提示。
  * 当类型属于 **银行卡类**(储蓄 / 信用 / 预付)或已填过卡号时,显示「卡号」行,可点击 →
    手机内输入弹层填写卡号;保存时自动按 **4 位分组**格式化(如 `6225 8801 2345 6021`),
    仅保留数字、最多 19 位。
  * 头部摘要显示类型与 `尾号 XXXX`。
* 新增账户子页面:类型选择后,若为银行卡类,自动出现「卡号(可选)」输入;保存时格式化。
* 数据类型新增 `cardNo` 字段;示例账户(招商银行储蓄卡 / 信用卡)带卡号。

### B. 记一笔:重新设计为「不滑动即可记账」

以 **一屏内完成记账** 为第一原则,重新组织信息层级:

* **上半区(仅两段,恒定不滚动)**:类型分段(支出/收入/转账)+ 大号金额。金额区块压缩留白。
* **分类区(唯一可变高度,占满剩余空间)**:仅一行**一级分类** chip + 一行**二级分类** chip。
  不再显示「父分类回退」幽灵 chip(默认已选中二级)。
* **转账时**:分类区替换为两行宽行「转出 / 转入」(宽行更适合长账户名)。
* **底部停靠区(始终可见,不滚动)**:新增 **四格快捷行**(账户 / 时间 / 标签 / 备注),
  数值直接显示在格内;点按即弹手机内选择器/输入弹层。
  * 标签、备注从「正文输入框」改为快捷格,避免键盘遮挡与横向溢出。
  * 快捷格数值 `ellipsis` 截断,保证四格横排不换行。
* 数字键盘与「保存」固定在快捷行之下;编辑态「删除」移到顶栏(不再占键盘下方空间)。
* 目标:在默认 390×844 视口下,`编辑页正文无纵向滚动`,且不需要收起键盘即可看到并修改账户/时间/标签/备注。

### C. 约束

* 单目录纯 HTML/CSS/JS,无外部依赖,`file://` 双击可开。
* 无假按钮:新增控件全部有真实效果。
* 不新增浏览器原生弹窗(`prompt`/`alert`/`confirm`)。
* `smoke-test.cjs` 覆盖:编辑页无滚动(正文 `scrollHeight <= clientHeight`)、快捷行四格可达、
  转账宽行、账户类型编辑、卡号 4 位分组格式化;并保持既有断言全绿。
* 更新 `README.md` / `BASELINE.md`(新哈希)。

## Acceptance Criteria

* [x] 账户详情可修改类型;银行卡类型可填写卡号并 4 位分组显示;头部显示尾号。
* [x] 新增账户选择银行卡类型时出现卡号输入,保存后正确格式化。
* [x] 记一笔正文在 390×844 下无纵向滚动;分类与金额、快捷四格与键盘同屏可见。
* [x] `[data-action]` 全部有处理器;无 `prompt`/`alert`/`confirm`;无脚本错误、无外部请求。
* [x] 冒烟测试全绿;README / BASELINE 同步(新哈希)。

## Out of Scope

* 不改 Android 源码;不做 Compose 迁移;深色模式不做。
* 卡号仅作展示字段,不做校验位/银行识别。

## Technical Notes

* 现状(`r3` 后):编辑页为 `typebar + amount + catArea + detailRow(mini-chip) + note-field`,
  正文会超出屏高需要滚动;`mini-chip` 若名称过长横向溢出。
* 改造点:`editView()` 只渲染 `typebar + amount + catArea`;新增 `editorDock()` 内的 `.quick-row`
  四格;`wide-row` 用于转账账户行;删除 `note-field` 改为 `pick-note` 弹层。
* 账户类型白名单与是否需卡号:`ACCOUNT_TYPES` + `typeNeedsCard()`;卡号格式化:`fmtCardNo()` / `cardTail()`。
