# UI redesign html prototype

## Goal

为 vip_ledger 做一套完整的 UI 重设计 HTML 原型：基于应用真实功能（五 Tab + 记账编辑），由 AI 全权决定视觉方向，产出一套好看、现代、有质感的手机端界面原型，作为后续 Compose 改版的视觉基准。

## Requirements

* **像真实 App 一样可交互的原型**,不是静态设计稿陈列:手机外壳内是一个能点击、能切换、能记账的前端应用。
* **原型与说明文字分离**:介绍文案、章节导航、设计系统说明放在手机**外部**的工作台(studio / notes)面板,手机内只呈现应用界面本身。
* 目录结构 (参考 `NasTools/prototypes/nastools-ui`):
  * `index.html` — 外壳:图标 sprite、左侧工作台(品牌/文案/章节导航/色卡)、中间手机、右侧逐页说明、底部弹层 dialog。
  * `style.css` — 样式与设计 token;桌面三栏布局,窄屏(≤740px)退化为整屏手机。
  * `app.js` — 纯前端交互:状态、页面视图、动作分发、事件委托;内存数据,无网络请求。
  * `README.md` — 使用方式、设计方向、页面与交互清单、演示边界。
  * `BASELINE.md` — 设计基准登记(确认范围、文件摘要、后续变更记录约定)。
* 以手机屏幕(390×844)呈现,双击 `index.html` 即可打开,无控制台报错、无外部网络请求。
* 覆盖核心页面:
  1. **首页** — 月度支出概览 Hero、预算/今日/储蓄/七日趋势卡片、待审草稿、按日分组流水。
  2. **日历** — 月历 + 选中日收支 + 当日流水 + 记一笔入口。
  3. **资产** — 净资产总览、资产/负债分组账户列表、储蓄目标、资产趋势入口。
  4. **统计** — 时间段切换、收支概览、分类占比图表、排行、趋势。
  5. **我的** — 账本、计划（报销/借贷/分期/理财）、AI 配置、数据备份分组。
  6. **记一笔（编辑页）** — 金额输入、分类网格（二级展开）、账户/时间/标签、底部保存。
* 附带设计系统说明区：配色 token、字体层级、组件样式（卡片/按钮/徽章），便于后续映射到 Compose `VipLedgerTokens`。
* 数据用贴近真实的示例账单填充（中文商户、真实金额）。

## Technical Approach

**设计方向（AI 决策）：「墨绿金 · 静奢记账」(Quiet Luxury Ledger)**

* 延续品牌绿但升级质感：暖象牙白纸感背景（#F7F5F0 系）+ 深墨绿主色（#1A3C34 系）+ 黄铜金点缀（#B08D57 系）。
* 编辑感排版：衬线展示字体（数字/标题，Noto Serif SC / Georgia 系）+ 无衬线正文（system-ui / PingFang SC）；大号等宽数字做金额。
* 卡片克制：1px 发丝边框 + 极浅阴影，圆角 16px；Hero 区用深墨绿纯色/微渐变 + 金色细节，不再用大渐变。
* 语义色：支出赭红 #C0392B 系、收入松绿 #2E7D5B 系、转账靛蓝 #3B5B7A 系。
* 间距 4pt 网格，触控目标 ≥44px，与现有 `VipLedgerTokens` 4dp 网格可映射。

**实现**:纯 HTML + CSS + 原生 JS(无框架、无依赖),`index.html` / `style.css` / `app.js` 三文件;手机外壳内是一个内存态 SPA(状态机 + 视图函数 + 事件委托),左侧工作台承载章节导航与文案,右侧 notes 面板逐页讲解。「设计系统」说明独立成页(在工作台章节中)或落到 README,避免与界面混排。可参考实现:`C:\Users\hanhu\Code\NasTools\prototypes\nastools-ui`。

## Decision (ADR-lite)

**Context**: 用户无法口述参考截图风格，授权 AI 全权设计；需在现有 V2 设计系统（绿主色、语义色、4dp 网格）与全新视觉之间取平衡。
**Decision**: 不推翻品牌绿，做「静奢」升级：纸感浅底 + 墨绿 + 金点缀 + 衬线数字，编辑感排版替代 Material 卡片堆叠。
**Consequences**: 与现有 Compose token 映射成本低（主色/语义色/网格均可对应）；衬线数字在 Compose 需引入字体资源，属后续工作。
