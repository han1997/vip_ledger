# 支付完成自动记账

## 已确认需求
- 微信、支付宝、京东、拼多多、淘宝：通知 + 无障碍文字 + 本机中文 OCR。
- 固定账本、付款方式与实际账户绑定；明确才自动入账，其他进入独立待确认队列。
- 消费、收款、自转、退款；疑似借还款待确认。退款到账当月冲减支出，支持关联原消费与部分退款。
- 多源幂等、跨应用疑似重复待确认；修改/撤销仍保留凭据。
- 本机离线，不保存截图，不采集无关聊天；授权与服务状态分开显示。
- OPPO X8 Ultra / Android 17 / ColorOS 17 优先；小米、vivo 设置引导。自行安装，无 Root/Hook/录屏。
- 数据库无损升级、旧备份兼容、导出/余额/首页/统计统一退款口径。

## 实现与验收
1. 领域解析、独立候选、绑定与原子入账；退款类型与统一统计。
2. 系统采集服务、本机 OCR、设置/记录/确认界面。
3. 迁移/备份/解析/幂等/退款测试；test assembleDebug assembleRelease lintDebug。
4. 真机采集验证优先；无连接真机时明确记录未验证，不用合成样本宣称五平台兼容。

## 依据
- Android NotificationListenerService、AccessibilityService 官方接口。
- 无障碍截图 API 30+；窗口截图 API 34+；安全窗口不可绕过。
- ML Kit bundled Chinese text recognition，离线随包模型。
- 原设计见当前会话已确认 proposed_plan。
