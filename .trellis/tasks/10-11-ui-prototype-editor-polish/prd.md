# Prototype polish: editor keypad, seconds, subcategory logic

## Goal

在已确认的 `docs/ui-prototype/`(Concept 01 墨绿金)上做一轮**记账页聚焦**的打磨与补全,
让它更接近"未来的 App":数字键盘更精致、时间精确到秒、一级→二级分类的选择逻辑与真实 App 一致,
并补齐编辑页缺失的功能(备注、标签、删除、转账、AI 入口、金额格式)。

## Requirements

### A. 美化(用户明确指定)

1. **数字键盘**
   * 每键 4 列布局保留,但升级视觉:更大的按键、描边/按下反馈、阴影与圆角更克制;
     底部对齐手机安全区,不随内容滚动。
   * 金额显示:整数部分千分位,小数部分按输入保留;无小数时不补 `.00`(避免与输入冲突)。
   * 键盘提供收起/确认(⌨ 折叠),收起后可直接阅读并操作下方全部分类与详情。
   * 支持真实键盘输入(0-9、小数点、退格)与键盘高亮反馈。

2. **时间精确到秒**
   * 「时间」字段与选择器升级为 `HH : MM : SS`(与真实 App `parseEntryClock(hour, minute, second)` 一致)。
   * 时/分/秒各自步进(+/-),另有「此刻」按钮;分钟步进 5、秒步进 5(可按住微调)。
   * 列表/详情展示保持 `HH:MM`,编辑页字段显示完整 `HH:MM:SS`。

3. **一级分类 → 二级分类逻辑(对齐真实 App)**
   * 一级网格首格为「不选分类」,点击即清除选择。
   * 点一级分类:展开其二级区,二级区**插在它所在那一行下方**(不是整体挪到末尾)。
   * 二级区含「清除」(= 选中该一级本身) + 全部二级项;**一次只展开一个**一级。
   * 已选二级时,父级格保持选中态;右侧标题显示「一级 / 二级」。
   * 再次点击同一一级可收起。

### B. 补全功能

4. **备注**:页内可编辑输入(不再用 `window.prompt`),支持清空,空态为占位符。
5. **标签**:搜索 + 新建(同名复用),页内选择列表;未选时显示「添加标签」。
6. **删除账目**:编辑已有账目时提供删除入口,二次确认(危险按钮),删除后返回列表。
7. **转账**:转账类型提供「转出账户 / 转入账户」两个字段(不再共用单一账户)。
8. **AI 记账入口**:金额输入旁提供 AI 入口(与真实 App 一致),以弹层说明语音/文字/截图入口。
9. **金额千分位**:所有金额展示统一千分位 + 两位小数;输入态按 A.1 规则。
10. **账户明细**:资产页点账户,弹出该账户的真实流水(取自演示数据)。
11. **统计下钻**:统计页点分类排行,弹出该分类的流水明细。
12. **首页搜索**:实现按商户 / 备注 / 金额的关键词过滤,结果以列表呈现。

### C. 约束

* 仍为单文件目录结构,纯 HTML/CSS/JS,无外部依赖,双击可开。
* 原型与说明文字保持分离;说明文案不进入手机内。
* `smoke-test.cjs` 覆盖新增交互(键盘、秒、二级逻辑、删除、转账、搜索),保持全绿。
* 更新 `README.md` 与 `BASELINE.md`(新哈希待确认)。
