# VipLedger UI 重设计原型 · 01

面向后续 Compose 改版的**交互式**视觉基准。直接用 Chrome / Edge 双击 `index.html` 打开,
无需安装依赖、无需启动服务器;保留整个目录即可(HTML 会读取同目录的 CSS / JS)。

## 设计方向

- **墨绿金 · 静奢记账**:暖象牙纸感底 + 深墨绿主色 + 黄铜金点缀,替代纯白 Material 卡片堆叠。
- **编辑感排版**:展示与金额用衬线体,正文用无衬线;金额一律 `tabular-nums` 等宽数字、右对齐。
- **克制的卡片**:1px 发丝边框 + 极浅阴影,圆角 16px;Hero 用深墨绿微渐变 + 金色细节。
- **语义色**:支出赭红 `#B23A2E`、收入松绿 `#2E7D5B`、转账靛蓝 `#3B5B7A`;不做 alpha 变体。
- 间距走 4pt 网格,触控目标 ≥44px,与现有 `VipLedgerTokens` 可映射。

## 结构与原则

原型与说明分离:左工作台放文案/章节导航/色卡,手机内只呈现应用界面,右侧为逐页说明。

**两条硬性原则(本版确立):**

1. **无假按钮** —— 原型内每个可点元素都产生真实效果(状态变化 / 数据更新)。冒烟测试会遍历所有
   `data-action` 并断言都有处理器。
2. **所有页面在原型内** —— 二级功能不用「说明弹层」敷衍,而是在手机外壳内渲染独立子页面
   (带返回、可滚动、可增删改);选择器(账户/日期/时间/标签)为手机内底部弹层。

| 区域 | 内容 |
|---|---|
| 左 · 工作台 | 品牌、提案文案、章节导航、色卡、设计系统入口。**不属于应用界面。** |
| 中 · 手机 | 可交互的应用本体(内存态 SPA)。只呈现界面。 |
| 右 · 说明 | 逐页设计说明与「试着操作」清单。**不属于应用界面。** |

文件:`index.html`(外壳)、`style.css`(样式与 token)、`app.js`(交互)。

## 页面与交互

1. **首页** — 月度支出 Hero、可自定义卡片(预算/今日/储蓄/七日趋势)、待确认草稿、按日分组流水、
   右上角搜索与卡片设置。
2. **日历** — 翻月、有账日金点、选中日收支与流水、记一笔携带选中日期。
3. **资产** — 净资产 Hero、资产/负债分组账户与明细下钻、储蓄目标、资产趋势、新增账户。
4. **统计** — 时间段切换、账户/分类筛选、环形占比、分类排行下钻、月度趋势。
5. **我的** — 账本/分类/标签、计划(报销·借贷·分期·理财)、AI 配置(模型·商户规则)、
   数据(备份·导出·隐私)全部打开**手机内真实子页面**,可增删改。
6. **记一笔** — **页面永不上下滑动**(实测全部状态零滚动);层次对标主流记账软件。
   * 顶部:类型分段(支出 / 收入 / 转账)。
   * **分类:图标方块**。一级为 **5 列圆形图标**(46px,首字 + 名称),
     选中者填充墨绿渐变;点中一级后,其**二级分类以浅底胶囊面板直接插在「它所在那一行下方」**。
     分类区是唯一可内部滚动的区域;**点一级分类后若二级面板被裁切会自动滚入视野**
     (`revealSubPanel`),无需手动滑动找二级。
   * **备注 + 金额同一行**:备注为**真实输入框**(点按直接弹系统输入法,不弹窗);
     金额在右侧大点击区(48×88px,点按收起输入法回到数字键盘),31px 按类型着色。
   * 底部一行胶囊:**账户 / 时间 / 标签 / AI 记账**。
   * **数字键盘常驻**:3 列 × 4 行,单键 78×46px;右侧竖条为保存。
   * **日期与时间合并**为一个选择器:上方月历 + 下方 `时:分:秒` 步进;显示今天/昨天。
   * 转账时分类区换成两行宽行「转出 / 转入」。
7. **账户详情(子页面)** — 展示图标/名称/余额/分组类型/**卡号尾号**/备注/创建时间与近期流水;
   可重命名、改备注、**修改类型**、**银行卡可记录卡号(4 位分组)**、**余额校准**
   (生成不计收支的调整记录)、归档/恢复、删除。资产页有「已归档账户」入口。
   新增账户含名称/分组/类型/卡号(银行卡类)/初始余额/备注。

### 补充能力

- 首页搜索(商户 / 备注 / 标签 / 账户 / 金额,实时过滤)。
- AI 记账子页面:示例文案 → 解析 → 填入记一笔。
- 统计「自定义」区间:起止日期选择并真实过滤;统计筛选(账户 / 分类)。
- 资产趋势折线(由记账数据推导)、储蓄目标存入/取出。
- **导入账单子页(v2.3)**:「我的 → 数据 → 导入账单」。一木记账账单(.xls / .zip)导入,
  四态齐备:选文件(空态)→ 预览(摘要卡 + 落点二选 + 将新建分类 34 / 账户 18 可折叠清单,
  选「导入当前账本」时走二次确认)→ 导入中(进度条 + 已处理 x / 6008 行)→ 报告(新增 / 重复 /
  失败 / 跳过 / 新建分类 / 新建账户)。原型用演示数据模拟,不真正读写文件。
- **无浏览器弹窗**:新增项(账本/标签/报销/借贷/分期/理财/商户规则/账户名称等)
  统一用手机内输入弹层,不使用 `prompt`/`alert`/`confirm`(冒烟测试用探针拦截)。

## 演示边界

- 不联网、不读写设备、不调用任何后端;数据只在当前页面内存中,刷新即重置。
- 搜索、分类明细、账户明细、报表二级页等仅以弹层说明呈现,不实现完整流程。
- 深色模式、动效细节与线索区(报销/借贷/分期/理财)的二级管理页不在本轮范围。
- 报表数字为演示数据,不代表真实账户余额。

## 验证

冒烟测试 `smoke-test.cjs`(Playwright):断言六页可达、日历选日、统计切换/筛选/**自定义区间**、
编辑器一屏不滚动、分类恒有值、**日期时间合并选择器**、手机内弹层与子页面、搜索、转账、删除、
**账户重命名/改类型/卡号/校准/归档/恢复/新增**、所有「我的」子页面可交互、导出/备份/预算/卡片真实生效,
以及**遍历所有 `data-action` 断言均有处理器(无假按钮)**、**无浏览器原生弹窗**、
无外部请求、无脚本错误。
本机有 Playwright 时执行:

```bash
PLAYWRIGHT_MODULE=<本机 playwright 模块路径> node smoke-test.cjs
```
