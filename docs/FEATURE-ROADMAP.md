# 截图参考功能完善路线（2026-10-09）

## 已确认目标

参考用户提供的一木记账四张截图，功能与界面一起完善，保留 VipLedger 原生 Android 技术栈和绿色设计系统。首批交付首页、预算、日历。完整个人台账包括报销、借入借出、分期、房贷和理财；语音优先系统离线，系统联网转写单独开关且默认关闭；报销先计支出，到账冲减到账月份支出。

维持单用户、人民币、本地优先；云端 AI 可选、WebDAV 只备份。此次不引入多设备同步、自建服务、共享账本、行情和桌面小组件。截图小卡片指应用内首页卡片。

## 最终导航与界面

首页 / 日历 / 资产 / 统计 / 我的五 Tab，各自保存状态，二级页隐藏底栏。第一批先四 Tab，资产页完成后加入第五个入口，不放空壳。

- 首页：账本切换、搜索、资产/本月概览、记一笔、双列小卡片、待处理、按日流水。
- 日历：周一起始的月历、每日收支、月汇总、选中日流水、返回今天、按选中日记账。
- 资产：总资产/负债/净资产、分组账户及流水、报销、借贷、分期房贷、理财。
- 统计：日/月/年/自定义、收支及资产趋势、分类/标签/账户、下钻和导出。
- 我的：管理、首页配置、自动记账、语音/AI、周期规则、备份恢复、安装版本。

复用现有 tokens、卡片、图表、语义色；深色、大字体、小屏可用，卡片均来自真实数据并通向详情。

## 阶段与验收

### P0 路线与兼容基础

将路线挂入 docs/PLAN.md，建立总任务和阶段子任务，修正旧规划状态。统一统计与日期刷新契约，准备旧库、旧备份和已知账目回归。阶段状态区分代码、自动测试、模拟器、真机。

### P1 首批：首页、预算、日历

依次完成共享汇总/日期刷新、预算、日历、首页整合。

- 首页：总资产、本月结余、剩余预算、本月支出；明确记一笔；预算、今日收支、近七天支出、待处理四卡；按日近期流水，点击直接编辑。长驻跨日/月和时区变化自动刷新。
- 预算：自然月总预算、一级/二级分类预算；额度沿用上一有效设置、不滚存余额，某月修改不回写过去。总额和各级独立约束，父级包含子级消费，禁止重复累计。已用/剩余/比例/超支；退款及报销冲减发生月；80%/100%每月每档提醒一次，无通知权限仍应用内提示。未设置、零额度、负净支出及超支状态明确。
- 日历：周一起始，切月/返回今天；日期格收入/净支出、月汇总、选中日流水；记账预填日期。账本切换、重启、编辑/删除、日期变化一致。
- 验收：同一笔100元支出在首页/日历/预算/统计一致；跨月退款一致；配置重启和备份恢复保留；四 Tab 没有空入口。

### P2 资产、储蓄、首页配置

- 资产分组：资金、信用、充值（新增类型）、应收应付、贷款、投资；详情、转账、调整、归档，排除净资产标识明确。汇总对同一纳入账户集合取正余额为资产、负余额绝对值为负债，净资产为两者之差。
- 建立可验证资产历史基线，不伪造升级前曲线。
- 储蓄：名称、目标金额、截止日、存入/取回、完成/归档。进度关联实际转账，分配记录不再次改变余额。
- 首页配置按账本持久化：卡片显隐、排序、恢复默认；加入储蓄卡片，默认预算/今日/储蓄/七日。
- 验收：转账及储蓄不虚增净资产；配置和目标完整备份；五 Tab 状态保持。

### P3 报销与借贷

- 已有支出创建报销项目，支持多费用、对象、备注、凭证、部分/全部到账及终止。到账关联原支出，使用退款方向并标明报销用途，继承原分类及统计排除设置。退款+报销共用原消费金额上限。待报销独立展示、不重复成为应收资产。多费用分配原子提交。
- 借出/收回/借入/归还、部分结清、利息、到期提醒；本金在资金与应收应付账户间流转，利息计收支。原始/剩余本金、结清记录、关联流水。
- 验收：本月支出1000，下月到账600：本月支出1000，下月冲减600，待报销400；重复到账和超额到账拒绝。

### P4 分期、房贷、理财

- 复用计息引擎，本金/利息/手续费分开入账。计划区分已有负债与新放款，防止本金重复。
- 逐期核销、部分还款、提前结清；部分提前还款默认保持余期数、重算后续，已还不改。利率变更从指定未还期生效；自定义期提供本金/利息/费。
- 旧分期保留兼容结果，提供差异预览及用户显式修正，不静默重写历史。
- 理财为金额台账：投入/追加/赎回本金是转账，已实现收益为收入、损失/费用为支出；展示在投本金/累计投入/已实现收益，不接行情或自动估值。
- 验收：本金1000+利息50+费10，资金-1060，负债减1000，支出60；关联操作整体改删恢复。

### P5 文字、语音、截图

- 四种输入统一编辑器/草稿确认；一句多笔可逐笔修改、批量确认，区分未识别字段。
- 语音按住/松开/取消/重试/转写编辑，离页停止，不存原始音频。系统端侧检测；联网转写独立开关默认关；无服务/权限/超时可改手工。
- 主动选图及系统分享、多图逐张 OCR，复用本机中文识别；金额/商户/时间/支付方式/订单号。冲突须补充；主动截图始终先确认。原图默认不存，可选附件。
- 技术参考：https://developer.android.com/reference/android/speech/SpeechRecognizer 、https://developer.android.com/training/data-storage/shared/photopicker 。系统识别可能联网，不能将普通服务冒称离线。

### P6 自动记账与平台验收

保留通知/无障碍/OCR，完善候选/已入账/忽略入口。截图与自动采集共享可靠凭据判重，疑似重复人工处理；固定账本、绑定、来源、账目编辑保持。微信/支付宝/京东/拼多多/淘宝分别记录真实通过条件。历史/冲突/缺绑定/退款关系不明继续待确认。用户操作真机页面与支付，合成样本不代表平台验收。

### P7 报表

日/月/年/自定义；收支趋势、两级分类、标签账户排行、资产/负债/净资产趋势。图表排行同一数据，下钻传完整条件；多标签声明重复归属，负分组用带符号列表。资产从基线开始、改删补记重算，基准日前补记作为基准修正。CSV/PNG带账本/区间/口径，保留组合搜索。

### P8 贯通验收

新装/旧版升级/恢复、多账本、长驻、空态/取消/返回/重试、大字体深浅主题、十万流水查询与滚动。连续30天实际使用观察不阻塞已验收阶段交付。完成说明、模型、规范和验收记录。

## 技术与交付约束

沿用现有分层，领域计算与仓库接口不依赖 Android。新增预算、首页配置、目标/分配、报销/到账、借贷、理财操作及资产历史模型。新增领域读用例供首页/日历/预算/报表共用。关联账务操作的写入/改删/恢复及余额维护均为单事务。

金额整数分；仅已确认、未删除、未排除的收支进入统计；本金转账不算收支。Room从schema2增量迁移，禁止毁库。新表/枚举/关联同步 JSON 与快照清单，旧格式缺失字段有明确定义。新增预算/目标/配置/关系完整备份，恢复仍关闭自动采集并清空平台验证。

每阶段跑 test assembleDebug assembleRelease lintDebug 与相关迁移/模拟器验证。每轮应用交付仅 bump 一次（默认patch）并更新 CHANGELOG；安装精确匹配当前版本签名 Release、applicationId fun.han1997.vipledger。真机连接时直接 adb -s 真机 install -r 并核验，不卸载、不自动操控真机页面。
